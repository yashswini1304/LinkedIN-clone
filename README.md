💼 LinkedIn Clone

A front-end LinkedIn Clone built using HTML, CSS, and JavaScript only — no frameworks, no backend.
This project replicates the UI and basic interactions of the LinkedIn web app, focusing on layout, design, and user experience.

🧠 Overview
This project is a simplified clone of LinkedIn, designed to practice front-end web development skills such as:
Building complex layouts with HTML & CSS
Creating responsive designs
Implementing interactivity using Vanilla JavaScript

🚀 Features

🏠 Home Feed UI — displays posts and stories similar to LinkedIn

👤 Profile Section — includes profile photo, connections, and activity

📰 Sidebar Widgets — for trending news and recommended connections

💬 Post Creation Box — allows simulated post input and dynamic post rendering (front-end only)

🌓 Responsive Layout — optimized for desktop, tablet, and mobile views

🎨 Custom Styling — clean and modern UI using CSS Flexbox and Grid

💡 Key Sections

1. Header / Navbar
Contains logo, search bar, and navigation icons.
Sticky top navigation bar that remains visible while scrolling.

2. Sidebar
Displays user profile card and “Connections” info.
Contains shortcuts and recommended pages.

3. Main Feed
Shows dynamic posts with images, names, and captions.
Optional post creation box implemented via JavaScript.

4. Right Sidebar
Includes trending topics, news, and ads.
